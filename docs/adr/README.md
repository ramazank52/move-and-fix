## Format

Her ADR şu bölümleri içerir:
1. **Bağlam** — Kararın alındığı durum
2. **Karar** — Ne karar verildi
3. **Gerekçe** — Neden bu karar verildi
4. **Sonuçlar** — Kararın getirdiği kısıtlar ve avantajlar
